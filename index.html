操作说明

按顺序做完即可，不必一次理解全部协议名词。客户端界面用词可能略有差别，抓住「订阅 / 导入 / 更新 / 连接」四个动作。

  1. 01打开套餐区域，对照流量与设备需求选择档位并完成订阅。
  2. 02在账户或订单页复制订阅地址，只保存在你自己的设备或密码库中。
  3. 03前往客户端下载，选择与系统匹配的版本并完成安装。
  4. 04在客户端中选择从 URL 导入或添加订阅，粘贴地址后保存。
  5. 05更新列表，挑选线路连接。首次建议先打开普通网页确认是否通畅。
  6. 06若失败，切换线路、检查系统时间与网络权限，仍未恢复则对照下方问答排查。

订阅地址不是普通网站链接，不要在浏览器地址栏直接打开，也不要发到群聊。重置后旧地址会失效，所有设备都需要重新导入。

常见问题

把配置过程里最容易卡住的点写成问答。先展开与你当前步骤相关的一条，通常不必通读全部。

365VPN 是什么？和机场订阅怎么对应？

365VPN 是以机场订阅交付的网络加速服务。你购买套餐后得到订阅地址，再在客户端里导入，即可按套餐约定使用连接。365机场指的就是这一套「订阅 + 客户端」的组织方式，而不是另需安装的浏览器插件。

第一次使用需要准备哪些东西？

准备一台你有安装权限的设备、可用的本地网络，以及本页的套餐与下载入口。订阅完成后复制完整订阅地址，下载对应系统客户端，按「导入 — 更新 — 连接」操作。建议同时记下下单邮箱或账户名，便于以后重置订阅。

如何把订阅导入客户端并连上？

打开客户端，找到订阅、配置或 URL 导入入口，粘贴地址后保存。执行更新，待列表出现线路后再点连接。不同客户端按钮文案不同，但顺序一致。导入失败时先检查地址首尾是否有空格、是否被截断成两行。

客户端应该下载哪一个？安装后无反应怎么办？

以操作系统为准，在本页客户端下载模块选择匹配版本。安装后若无法打开，确认是否被系统拦截、是否需要授予网络或 VPN 配置权限，并核验是否下错架构。不要混用其他来源的旧版本配置文件。

连接失败或频繁断开如何排查？

先确认关闭客户端时本地网络本身可用，再检查设备时间是否准确。接着更新订阅、更换线路重试。若所有线路均失败，删除旧订阅后重新导入。仍无法使用时，记录客户端名称、系统版本和报错原文，再通过套餐所提供的支持渠道说明。

套餐怎么选？正文为什么不写价格？

按每月大概用量、需要同时在线的设备数量，以及对支持响应的要求来选。价格、流量和设备上限写在上方套餐模块里，以免正文和报价不一致。年付说明也以该模块为准，选定后按页面提示完成订阅即可。

订阅地址可以分享给同事或发到群里吗？

不可以。订阅地址相当于使用凭证，被转发后可能被占用流量，也增加被滥用的风险。多人使用应选择与设备数量匹配的套餐，并控制转发范围。若已泄露，立即重置订阅，并在所有客户端里替换新地址。

365VPN 官网下载和推荐操作顺序是什么？

推荐顺序是：阅读简介与场景 → 查看套餐 → 完成订阅 → 在官网下载客户端 → 导入订阅 → 连接。遇到阻碍再回到本栏常见问题。不要跳过导入去寻找来路不明的线路文件，以免拿到过期或被改动的配置。
